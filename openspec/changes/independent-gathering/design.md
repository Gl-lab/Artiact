# Design

Introduce common character observation for identity, location and inventory. Gathering validates its own profession fields and compares unchanged raw character fields outside the documented action mutation set; combat keeps its strict normalizer. Optional combat is represented by target 0 with empty monster/equipment; partial configuration is rejected. Equipment may be omitted when combat is enabled.

Factory derives strategies and catalogs from policy. Compatibility checks receive the same policy, with legacy callers retaining the existing full probe. Use real clients over TestServer, injecting unsupported combat characteristics into all observations and replies. No production host execution is needed.
