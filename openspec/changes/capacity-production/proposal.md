# R8: Capacity-aware production and protected stock

## Scope

Use an opt-in production policy to separate order totals from the next executable batch. Count bank-owned final output toward completion without withdrawing it merely to reconstruct the order. Plan bounded recipe batches, obtain ingredients, deposit allowed surplus under inventory pressure, and retain the materials needed for the next craft. Reserve protected quantities and already-owned quantities serving other item goals so that one goal cannot consume another's completed output. All decisions use fresh actual inventory/bank and the existing one-command journal.

## Acceptance

A five-tool order larger than a three-unit inventory completes through bounded nested bar/tool crafts and bank deposits, conserving ten gathered ore as five tools while retaining a protected item. Multiple goals sharing an ingredient preserve final quotas. Lost deposit/withdraw/craft replies reconcile without repeating POST. Impossible minimal recipes, full/inaccessible banks, protected-stock conflicts and external changes produce bounded refusal. R7 preparation remains enabled in a constrained-capacity scenario.

## Non-goals

Global optimal routing, trading/destruction, distributed/multi-character reservations, live acceptance or unrelated Legacy rewrites.
