# R9: bounded autonomous combat preparation

Select a reachable ordinary opponent and a supported weapon or shield upgrade for successive combat milestones. Reuse skill preparation, capacity-aware production and immediate healing. Keep the live-combat no-go in ADR 0001.

Affected: Combat normalization/projection, Strategy policy/factory/actions, API probes, application and real-client mock tests, operational documentation. No new shared DTO or live action is required.
