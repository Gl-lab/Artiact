# R25 — Needs-driven bounded goals

Status: R25.1 design before R22. Runtime implementation and acceptance remain open until after R24.

Introduce an explicit needs mode alongside existing configured goals and explicit general development. Supported parents are operator item orders and observed HP deficit with enabled Recovery. A capability/skill obstacle is a child of one such parent, never an independent source of utility. Reuse supported production/preparation/recovery actions. Do not add professions, potion effects, combat, economy, automatic permissions or unbounded schedules.

The complete roadmap acceptance matrix in `docs/roadmap-inventory-progress-ru.md` R25.4 is normative. This change supplements it with persistence, compatibility and boundary decisions.
