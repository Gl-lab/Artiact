# Design

Keep this field-trial harness in the excluded RealApiTests project. The existing read allowlist supplies catalogs and character. A transport decorator builds the latest observation from complete ordered pages, checks the pinned policy/world and initial character fingerprint, and permits only the exact proposed commands after fresh observation. Clear the observation after every dispatched action. Serial dispatch and a permanent in-memory failure latch supplement the production flushed-intent journal; they never replace it.

After a successful action reply reports the scoped milestone, request the shared operator stop token. Production execution still validates and journals the reply before observing cancellation. Rejections before dispatch are typed Rejected, not unknown; failures after dispatch remain ambiguous and latch further actions. Never replay an existing harness directory; terminal reopen is verified through the shared execution path.

Harness uses MapOperator, OperatorCoordinator, StagedExecution, StrategySessionFactory and OperatorSnapshotReader, with no automatic Start. One stable RunId/directory, ceilings16/20/3/900, pinned official origin, no redirects. Credentials remain in ignored .env and memory. Live opt-in is a separate exact environment value; tests never enable it. The final reviewed commit and fresh Inspect must precede user action approval.
