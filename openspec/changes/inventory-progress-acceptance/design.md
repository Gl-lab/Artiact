Use synthetic planner facts for deterministic refusal, existing TestServer intermediate/bank/restart scenarios for execution and the actual embedded panel with synthetic HTTP responses for browser inspection. No host with game credentials is needed for panel QA. R21 browser tests verify duplicate clicks and refused preparation; R22 TestServer proves intermediate completion across restart; R23 bank tests verify conservation and ambiguous replies.

The production API harness's RealApiBudgetAssessment loads one snapshot through its guarded GET allowlist and evaluates finite cases locally. Preserve prior environment flags. Passing assessment means inspection ran, not necessarily a Selected row. Bank expansion of the read-only allowlist is not needed for this no-bank acceptance and is excluded.
