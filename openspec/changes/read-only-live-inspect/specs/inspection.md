# Inspection boundary

The explicit opt-in shall execute production Inspect for mining target 2 without hosting and report a decision with zero action attempts. A blocked decision fails actionable live acceptance and retains its rejection reason.

Only OpenAPI, the configured character and positive paginated maps/resources GETs are allowed. Other routes and every POST fail before the network callback. Authentication is separate and pinned to the official token endpoint. Reports omit credentials and raw character/catalog state.
