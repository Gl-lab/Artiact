# Behavior

- Measured selection is opt-in; fixed-policy regression behavior remains.
- Multiple supported resources become distinct candidates; explicit opponents and existing item targets compete under the same safety predicates.
- Verified cooldowns update finite positive estimates; unknown/rejected outcomes do not create samples. Missing estimates are marked Assumed with a conservative multiplier.
- Close scores retain incumbent; significantly better feasible scores switch. Ordinal IDs break initial ties.
- Independent slow/fast fixtures compare fixed and measured runs with the same four-action budget, reporting actions, returned seconds and goal completions, with reproducible replay. Synthetic savings do not establish live optimality.
