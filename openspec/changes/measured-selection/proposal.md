# R5 — Measured, explainable candidate selection

Opt-in measured ranking compares reachable resource alternatives and explicit opponent/item alternatives. Learn confirmed action cooldowns, preserve them with the run, expose estimate source/sample count, and retain the current goal unless a competitor exceeds a configurable switching ratio. Unknown estimates use an explicit conservative multiplier; no live optimal XP/hour claim.

Acceptance: deterministic independent scenarios compare actions, virtual seconds and completed goals against a fixed policy. Measurements come only from verified replies; alternatives still use normal eligibility/preflight and a common budget. Restart preserves samples and incumbent.
