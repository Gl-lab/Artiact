# Design

Implement a focused prerequisite wrapper over ItemProductionStrategy, enabled by Portfolio preparation configuration. Preserve current behavior when disabled. Use the existing complete production plan and stock ledger to find unsatisfied skills; keep the original goal identity/value when returning a prerequisite command. Commands must retain the full-world fingerprint and use the existing journal/reconciliation path.

Training selection is deterministic: eligible same-skill recipes, bounded ingredient count, supported empty conditions, positive output and known positive item level; exclude items at least ten levels below the skill. Order by requirement and code, evaluate feasibility and do not let an unavailable first candidate hide later feasible candidates. Produce one additional batch even if the character already owns training products. Training crafts must increase the specified skill's level or XP, preserve other fields and conserve stock. Intermediate moves/gathers/withdrawals reuse their existing postconditions. The global action budget bounds the number of training batches; the per-batch direct-material ceiling bounds direct training consumption by ceiling × action budget. Recursive ingredient production remains under the same action cap.

Resolve resource requirements using matching drop sources and current full catalogs. If none is usable at the current skill, return a gathering prerequisite to the lowest supported required level. Use a bounded path set to reject recursive item/skill dependencies. Recompute from actual observed state on every tick, and end preparation immediately when the final target is satisfied.

Official [skills documentation](https://docs.artifactsmmo.com/concepts/skills), read 2026-09-07, requires matching workshops and skill levels for crafting and describes zero XP when ten or more levels above an item/resource. The planner uses those eligibility boundaries, not a claimed exact XP/time forecast. The first synthetic crafting profession is weaponcrafting; mining supplies its resources. The public crafting contract already exists; no new endpoint is needed. Any expansion to another profession requires its observation/schema and scenario checks.
