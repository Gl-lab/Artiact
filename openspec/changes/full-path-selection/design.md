# Design

`FullPathSelection` opts into a new measurement mode; existing MeasuredSelection semantics and old identity serialization remain compatible. Candidates carry an explicit parent metric and route estimate. Evaluate at most bounded existing resource/opponent/item alternatives; reject unsupported estimates rather than manufacturing achievable progress. XP is exact for same-level or one-level transitions, unknown across larger unobserved boundaries; retain level delta separately. Combined inventory+bank deltas prevent bank moves masquerading as production. Equipment/supply steps retain their combat/item parent metric.

Verified journal facts include skill changes, stock delta, recipe/input consumption, used food, HP change, candidate/context, measured observation/dispatch time and separately completed cooldown wait. Intent/unknown/reconciled entries do not create timing or XP learning samples. Preserve facts before waiting; an interrupted wait remains explicitly incomplete. Run elapsed time includes downtime; completed active timing excludes downtime and is reported separately.

Measurement keys include parent/candidate, command and a digest of policy, catalogs, skill/combat levels, equipment, modeled modifiers and relevant capacity/access. Exclude transient XP/inventory from the learning context. Rest/use include HP/quantity; moves include origin. Context changes use estimates until new observations arrive. Keep finite storage limits via existing run action bounds.

Full-route estimates count required item recipe work, resource quantities, workshops/bank/travel/recovery, gear and food preparation. XP routes forecast to the next level using declared estimates or matching verified XP per action; future levels and training retain explicit uncertainty. Actual benefit per verified operation replaces successful-step counts for scoring. Never replace the entire route with a single fast prerequisite sample. All unmeasured assumptions are visible. Existing switching hysteresis persists; record candidate switches for reporting.
