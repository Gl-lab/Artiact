# Separate R6 live gathering/bank acceptance

Status: prepared protocol, not executed or authorized by implementation delivery.

## Select a concrete scope

Use the dedicated read-only verifier, never default host startup, to obtain current character level/XP, inventory, bank slots/stock, current map and eligible resource/bank map identities. Pin the official origin and current API subset. Record the exact source revision, character, initial observations and explicit target level. Select a reachable resource and bank route that require at least two deposits before target completion; if current inventory/capacity cannot establish this, do not claim that acceptance from a shorter route.

The separate rollout specification must enumerate the exact allowed Move map IDs, Gathering resource, deposited codes and retained quantities. It must set numerical action/decision/time budgets from the inspected route, approve a single fresh run identity and exclude craft, withdrawal, combat and all other actions. Do not reuse earlier one-shot or bounded live acceptance identities/markers. No numbers can be responsibly inferred from the dated mining-1/XP-26 report.

## Execute and reconcile

1. Run the matching local scenario and offline API boundary checks at the selected revision.
2. Obtain approval for the concrete live scope and budget, then dispatch through an exact origin/action allowlist and the durable Bounded journal.
3. On any unknown outcome, observe only. Preserve the journal and prohibit automatic repeats or archival.
4. Independently GET character and full bank after the run. Record target level/XP, protected items, inventory plus bank conservation, attempts, confirmed cooldown and stop reason.
5. Stop/restart the terminal host and verify zero additional actions. Inspect the offline result and archive only a verified completion using its identity digest.

Live completion is separate from R6 local code completion. A level not observed independently, fewer than two deposits, unavailable bank, or an exhausted budget is an incomplete acceptance result, not a reason to widen the rollout automatically.
