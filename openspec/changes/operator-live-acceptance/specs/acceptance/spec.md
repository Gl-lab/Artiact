# Acceptance

- Six decisions / three no-progress with positive action/time bounds are valid; zero/negative/inverted limits remain invalid. Panel cannot exceed server ceilings.
- Autonomous inspection reads paginated items only with explicit autonomous option; other-character paths, game POSTs and non-allowlisted paths never reach transport.
- Offline tests remain credential-free; live inspection remains separate and guarded. No read-only command can enable execution.
- For eventual live completion: reviewed commit, fresh identity/fingerprints, finite scope and explicit user approval precede action; unexpected commands are rejected at transport.
- UI preparation, start, observation, requested/confirmed stop, result and unchanged terminal state on reopen must be evidenced on the real API. Unknown results are retained and not retried.
- R16 unresolved history, unavailable credentials/data or missing concrete approval are reported as open scope. R20 is not called delivered before this gate.
